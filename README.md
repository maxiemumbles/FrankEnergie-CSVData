# FrankEnergie-CSVData
Dit is het repository voor een klein miniprojectje voor mijn vader, 
dat ik gebruik om ook mijn kennis met Java een beetje te bevorderen. 
Dit project is dus niet bedoeld voor grootschalig gebruik, aangezien
ik onzeker ben of dat wel mag van FrankEnergie. <br>
Het doel van dit repository is om de data van het jaar op te halen,
en dat in een mooi csv-bestand te zetten. <br>
## API Calls
Dit repository maakt gebruik van een GraphQL call op de website van FrankEnergie
dat de data per dag, per uur binnenkrijgt, dus niet dat van de kwartiervariant. <br>
De API is gevonden door middel van devtools te openen op de FrankEnergie website,
en de calls te inspecteren voor de API calls naar de server voor de grafiekjes.
# Quickstart
Hieronder volgt een kleine uitleg over het opstarten van dit porgramma.
## Benodigdheden
Om dit bestand succesvol te openen is Java 25 vereist, dit is te downloaden via:
https://www.oracle.com/java/technologies/downloads/#jdk25-windows
## Stappenplan
Bouw het bestand naar een .jar bestand om via een IDE (IntelliJ IDEA werkt hiervoor), en run dan het programma met java -jar (naam van programma).
